# 闯关练习系统详细设计文档

## 1. 闯关系统概述

### 1.1 设计理念
- **渐进式难度**: 从简单到复杂，循序渐进
- **场景化学习**: 真实生活场景模拟
- **多元化练习**: 文字+语音+互动相结合
- **成就感驱动**: 闯关成功的满足感激励持续学习

### 1.2 核心机制
- 关卡解锁机制 (前一关卡达标才能进入下一关)
- 星级评价系统 (1-3星评价练习质量)
- 重复挑战机制 (可重复练习提高星级)
- 特殊关卡奖励 (里程碑关卡有特殊奖励)

## 2. 关卡体系设计

### 2.1 总体结构
```
英语实用表达训练
├── 生活场景关卡组 (Life Scenarios)
├── 工作场景关卡组 (Work Scenarios)  
├── 学术场景关卡组 (Academic Scenarios)
└── 专业场景关卡组 (Professional Scenarios)
```

### 2.2 难度分级体系
**基础级 (Foundation Level)**
- 目标: 雅思5.0-5.5水平
- 特点: 简单对话、基础词汇、简单句式
- 关卡数: 每个场景组15-20关

**进阶级 (Intermediate Level)** 
- 目标: 雅思5.5-6.0水平
- 特点: 复杂情境、词汇变化、复合句式
- 关卡数: 每个场景组20-25关

**高级 (Advanced Level)**
- 目标: 雅思6.0-6.5水平
- 特点: 专业讨论、高级词汇、复杂逻辑
- 关卡数: 每个场景组15-20关

## 7. 练习形式详细设计

### 7.1 情境对话练习
**练习结构**
```
场景设定 → 角色分配 → 对话目标 → 用户输入 → AI响应 → 多轮对话
```

**示例关卡: 餐厅点餐 (L1-17)**
```
场景: 你在一家西餐厅准备点餐
角色: 你是顾客，AI是服务员
目标: 完成点餐过程，包括询问菜品、下单、特殊要求

AI: "Good evening! Welcome to our restaurant. Have you decided what you'd like to order?"
用户: [输入回应]
AI: [根据用户回应继续对话]
...
```

### 7.2 看图说话练习
**练习结构**
```
图片展示 → 描述要求 → 用户输入 → 评估反馈
```

**示例关卡: 描述日常作息 (L1-09)**
```
图片: 一天24小时的时间安排图表
要求: 用英语描述图片中人物的一天安排
评估点: 时间表达、动词使用、句式连贯性
```

### 7.3 角色扮演练习
**练习结构**
```
场景介绍 → 身份设定 → 任务目标 → 表演要求 → 用户输入
```

**示例关卡: 面试自我介绍 (W1-01)**
```
场景: 求职面试现场
身份: 应聘者
任务: 在2分钟内进行自我介绍
要求: 包含姓名、教育背景、相关经验、应聘原因
```

### 7.4 问题回答练习
**练习结构**
```
问题提出 → 思考时间 → 回答要求 → 用户输入 → 深入追问
```

**示例关卡: 表达个人观点 (A1-04)**
```
问题: "What do you think about online learning?"
要求: 表达你的观点并给出至少两个理由
追问: "Can you give a specific example?"
```

## 8. 评估标准设计

### 8.1 星级评价标准
**1星 (通过)**
- 基本完成任务要求
- 语法错误较多但不影响理解
- 词汇使用基础但恰当
- 表达简单但清晰

**2星 (良好)**  
- 较好完成任务要求
- 语法错误较少
- 词汇使用比较丰富
- 表达较为流畅

**3星 (优秀)**
- 出色完成任务要求
- 语法基本无误
- 词汇使用丰富准确
- 表达流畅自然

### 8.2 具体评估维度
**任务完成度 (40%)**
- 是否回应了所有要求
- 信息表达是否完整
- 交流目标是否达成

**语言准确性 (30%)**
- 语法错误数量
- 词汇使用准确性
- 拼写和标点正确性

**表达流畅性 (20%)**
- 句子连贯性
- 逻辑清晰度
- 表达自然度

**词汇丰富性 (10%)**
- 词汇多样性
- 高级词汇使用
- 恰当的同义词替换

## 9. 关卡解锁机制

### 9.1 线性解锁
- 必须获得前一关卡至少1星才能解锁下一关
- 同一系列内按顺序解锁
- 不同系列可以并行进行

### 9.2 里程碑解锁
- 完成某个系列的所有基础级关卡才能进入进阶级
- 获得足够的总星数才能解锁新的场景组
- 特殊成就解锁隐藏关卡

### 9.3 重复挑战机制
- 已完成关卡可以重复挑战
- 重复挑战可以提高星级评分
- 每次挑战都有新的练习内容

## 10. 数据模型设计

### 10.1 关卡信息表
```sql
CREATE TABLE levels (
    level_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    level_code VARCHAR(20) UNIQUE NOT NULL, -- L1-01, W2-05等
    level_name VARCHAR(100) NOT NULL,
    scenario_group ENUM('life', 'work', 'academic', 'professional'),
    difficulty ENUM('foundation', 'intermediate', 'advanced'),
    series_name VARCHAR(50),
    order_in_series INT,
    description TEXT,
    learning_objectives TEXT,
    estimated_duration INT, -- 预计完成时间(分钟)
    prerequisite_levels JSON, -- 前置关卡要求
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 10.2 练习内容表
```sql
CREATE TABLE level_exercises (
    exercise_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    level_id BIGINT NOT NULL,
    exercise_type ENUM('dialogue', 'description', 'roleplay', 'qa'),
    content_data JSON, -- 练习具体内容
    evaluation_criteria JSON, -- 评估标准
    difficulty_score INT, -- 难度分数
    FOREIGN KEY (level_id) REFERENCES levels(level_id)
);
```

### 10.3 用户关卡记录表
```sql
CREATE TABLE user_level_records (
    record_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    level_id BIGINT NOT NULL,
    attempt_count INT DEFAULT 0,
    best_star_rating INT, -- 最高星级评分
    completion_status ENUM('locked', 'unlocked', 'completed'),
    first_completed_at TIMESTAMP,
    last_attempted_at TIMESTAMP,
    total_practice_time INT, -- 总练习时间(秒)
    FOREIGN KEY (user_id) REFERENCES users(user_id),
    FOREIGN KEY (level_id) REFERENCES levels(level_id),
    UNIQUE KEY unique_user_level (user_id, level_id)
);
```

### 10.4 练习记录表
```sql
CREATE TABLE practice_records (
    practice_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    level_id BIGINT NOT NULL,
    exercise_id BIGINT NOT NULL,
    input_type ENUM('text', 'audio'),
    user_input TEXT, -- 用户输入内容
    audio_url VARCHAR(255), -- 语音输入文件路径
    star_rating INT, -- 本次评分
    feedback_data JSON, -- 详细反馈数据
    practice_duration INT, -- 练习时长(秒)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id),
    FOREIGN KEY (level_id) REFERENCES levels(level_id),
    FOREIGN KEY (exercise_id) REFERENCES level_exercises(exercise_id)
);
```

```

GET /api/levels/{levelId}/exercises - 获取关卡练习内容
POST /api/levels/{levelId}/unlock - 解锁关卡
