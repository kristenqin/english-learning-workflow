# 用户模块详细设计文档

## 1. 用户模块概述

### 1.1 模块职责
- 用户注册、登录、身份认证
- 用户个人信息管理
- 学习偏好和目标设置
- 个性化配置管理

### 1.2 核心实体
- User (用户基础信息)
- UserProfile (用户档案)
- UserPreferences (用户偏好)
- UserSettings (系统设置)

## 2. 用户注册登录模块

### 2.1 注册流程设计
```
用户访问注册页面
    ↓
填写基础信息 (邮箱/手机 + 密码)
    ↓
验证码验证
    ↓
完善个人档案 (可选)
    ↓
注册成功，跳转到首次使用引导
```

### 2.2 登录方式
**主要登录方式**
- 邮箱 + 密码
- 手机号 + 验证码
- 手机号 + 密码

**第三方登录 (可选)**
- 微信登录
- QQ登录
- Google登录

### 2.3 安全机制
- 密码强度验证 (至少8位，包含字母+数字)
- 登录失败锁定机制 (5次失败锁定30分钟)
- 设备绑定验证
- 异地登录提醒

## 3. 用户档案管理

### 3.1 基础信息
```
- 用户ID (系统生成唯一标识)
- 昵称 (用户自定义显示名称)
- 头像 (默认头像 + 自定义上传)
- 性别 (可选)
- 年龄 (可选)
- 注册时间
- 最后登录时间
```

### 3.2 教育背景
```
- 学历层次 (本科/硕士/博士)
- 专业方向 (工科/文科/商科/艺术等)
- 年级 (大一/大二/大三/大四/研一等)
- 学校信息 (可选)
```

### 3.3 英语水平档案
```
- 当前英语等级
  * 雅思分数 (听说读写分项 + 总分)
  * 托福分数 (可选)
  * 四六级成绩 (可选)
  * 自评等级 (初级/中级/中高级)

- 目标英语等级
  * 目标雅思分数
  * 预期达成时间
  * 学习动机 (留学/工作/兴趣等)

- 英语学习背景
  * 学习年限
  * 海外经历 (是/否，时长)
  * 主要学习方式 (学校/自学/培训机构)
```

### 3.4 职业目标
```
- 目标行业 (互联网/金融/教育/医疗等)
- 目标职位 (工程师/分析师/管理等)
- 工作经验 (在校生/实习/工作1-3年等)
- 对英语使用场景的预期
  * 工作邮件沟通
  * 会议发言
  * 客户交流
  * 学术论文
  * 海外合作
```

## 4. 学习偏好设置

### 4.1 练习偏好
```
- 每日练习时长偏好
  * 15-30分钟 (轻度)
  * 30-60分钟 (中度)  
  * 1-2小时 (重度)
  * 自定义时长

- 练习时间段偏好
  * 早晨 (6:00-9:00)
  * 上午 (9:00-12:00)
  * 下午 (13:00-18:00)
  * 晚上 (18:00-22:00)
  * 深夜 (22:00-24:00)

- 练习频率偏好
  * 每天练习
  * 工作日练习
  * 周末集中练习
  * 自由安排
```

### 4.2 内容偏好
```
- 场景偏好排序
  * 生活场景优先级
  * 工作场景优先级
  * 学术场景优先级
  * 专业场景优先级

- 练习形式偏好
  * 文字输入偏好程度 (1-5分)
  * 语音输入偏好程度 (1-5分)
  * 听力理解偏好程度 (1-5分)
  * 阅读理解偏好程度 (1-5分)

- 难度偏好
  * 喜欢挑战 (较难内容)
  * 稳步提升 (适中内容)
  * 建立信心 (较易内容)
```

### 4.3 反馈偏好
```
- 反馈详细程度
  * 简洁反馈 (仅评分+核心建议)
  * 标准反馈 (评分+详细分析+建议)
  * 详尽反馈 (全方位分析+扩展知识)

- 反馈时机
  * 即时反馈 (输入过程中)
  * 完成后反馈 (练习结束后)
  * 定期汇总反馈 (每周/每月)

- 鼓励方式偏好
  * 数据导向 (分数、进度条、统计)
  * 成就导向 (徽章、等级、排行)
  * 内容导向 (知识点掌握、技能提升)
```

## 7. 数据模型设计

### 7.1 User表
```sql
CREATE TABLE users (
    user_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(100) UNIQUE NOT NULL,
    phone VARCHAR(20) UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    nickname VARCHAR(50),
    avatar_url VARCHAR(255),
    status ENUM('active', 'inactive', 'suspended') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    last_login_at TIMESTAMP
);
```

### 7.2 UserProfile表
```sql
CREATE TABLE user_profiles (
    profile_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    gender ENUM('male', 'female', 'other'),
    age INT,
    education_level ENUM('undergraduate', 'graduate', 'phd'),
    major_category VARCHAR(50),
    grade_level VARCHAR(20),
    current_ielts_score DECIMAL(3,1),
    target_ielts_score DECIMAL(3,1),
    target_achievement_date DATE,
    overseas_experience BOOLEAN DEFAULT FALSE,
    learning_motivation TEXT,
    career_goal VARCHAR(100),
    target_industry VARCHAR(50),
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);
```

### 7.3 UserPreferences表
```sql
CREATE TABLE user_preferences (
    preference_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    daily_practice_duration INT, -- 分钟
    preferred_practice_times JSON, -- 偏好时间段数组
    scene_priorities JSON, -- 场景优先级配置
    practice_mode_preferences JSON, -- 练习模式偏好
    feedback_detail_level ENUM('simple', 'standard', 'detailed'),
    feedback_timing ENUM('immediate', 'post_completion', 'periodic'),
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);
```

### 7.4 UserSettings表
```sql
CREATE TABLE user_settings (
    setting_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    notification_enabled BOOLEAN DEFAULT TRUE,
    reminder_times JSON, -- 提醒时间配置
    privacy_level ENUM('public', 'friends', 'private') DEFAULT 'private',
    theme_preference ENUM('light', 'dark', 'auto') DEFAULT 'light',
    language_preference ENUM('zh', 'en', 'mixed') DEFAULT 'zh',
    font_size ENUM('small', 'medium', 'large') DEFAULT 'medium',
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);
```

## 8. API接口设计

### 8.1 认证相关接口
```
POST /api/auth/register - 用户注册
POST /api/auth/login - 用户登录  
POST /api/auth/logout - 用户登出
POST /api/auth/refresh - 刷新token
POST /api/auth/reset-password - 重置密码
```

### 8.2 用户信息接口
```
GET /api/user/profile - 获取用户档案
PUT /api/user/profile - 更新用户档案
GET /api/user/preferences - 获取用户偏好
PUT /api/user/preferences - 更新用户偏好
GET /api/user/settings - 获取用户设置
PUT /api/user/settings - 更新用户设置
```

### 8.3 头像上传接口
```
POST /api/user/avatar - 上传头像
DELETE /api/user/avatar - 删除头像
```
