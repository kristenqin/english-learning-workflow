# 反馈评估系统详细设计文档

## 1. 反馈评估系统概述

### 1.1 系统目标
- 提供准确、及时、有价值的学习反馈
- 帮助用户识别语言使用中的问题和改进点
- 引导用户向更自然、更地道的英语表达发展
- 个性化反馈，适应不同用户的学习需求和水平

### 1.2 核心评估维度
- **语法准确性**: 语法规则的正确使用
- **词汇运用**: 词汇选择的准确性和丰富度  
- **表达流畅性**: 语言表达的自然度和连贯性
- **任务完成度**: 是否有效完成交流目标

### 1.3 反馈层次
- **即时反馈**: 输入过程中的实时提示
- **完成反馈**: 练习结束后的综合评估
- **阶段反馈**: 定期的进步总结和建议

## 2. 语法评估子系统

### 2.1 语法错误检测
**时态错误**
```
检测范围:
- 时态选择错误 (过去时vs现在时vs将来时)
- 时态一致性错误 (同一语境下时态混用)
- 完成时态使用错误
- 进行时态使用错误

示例:
错误: "Yesterday I go to school"
检测: 时态错误，应使用过去时
建议: "Yesterday I went to school"
```

**主谓一致错误**
```
检测范围:
- 单复数主谓不一致
- 第三人称单数动词形式
- 集合名词主谓一致
- 就近原则应用

示例:
错误: "She like apples"
检测: 第三人称单数动词错误
建议: "She likes apples"
```

**句法结构错误**
```
检测范围:
- 句子成分缺失 (主语、谓语、宾语)
- 词序错误 (疑问句、感叹句)
- 从句连接错误
- 并列结构错误

示例:
错误: "I very like this book"
检测: 副词位置错误
建议: "I like this book very much"
```

**介词搭配错误**
```
检测范围:
- 固定搭配介词错误
- 时间介词使用错误
- 地点介词使用错误
- 动词介词搭配错误

示例:
错误: "I'm good in English"
检测: 介词搭配错误
建议: "I'm good at English"
```

### 2.2 语法评分算法
```python
def calculate_grammar_score(text, errors):
    total_words = len(text.split())
    error_count = len(errors)
    
    # 基础分数计算
    error_rate = error_count / total_words
    base_score = max(0, 100 - error_rate * 100)
    
    # 错误严重程度权重
    severity_weights = {
        'critical': 10,  # 严重影响理解
        'major': 5,      # 明显错误但不影响理解  
        'minor': 2       # 轻微错误
    }
    
    weighted_penalty = sum(severity_weights[error.severity] for error in errors)
    final_score = max(0, base_score - weighted_penalty)
    
    return min(100, final_score)
```

### 2.3 语法反馈生成
**错误标注**
```
原文: "I have went to Beijing last year"
标注: "I have [went→went] to Beijing last year"
说明: 现在完成时中应使用过去分词"gone"，或者改为一般过去时"I went"
```

**改进建议**
```
建议类型:
1. 直接纠正: 提供正确形式
2. 规则解释: 说明相关语法规则
3. 例句提供: 给出正确用法示例
4. 练习建议: 推荐相关语法练习
```

## 3. 词汇评估子系统

### 3.1 词汇准确性评估
**词汇选择准确性**
```
评估维度:
- 词义匹配度 (是否表达了想要的意思)
- 语境适应性 (是否适合当前语境)
- 语域适当性 (正式vs非正式场合)
- 搭配正确性 (与其他词的搭配)

示例分析:
用户输入: "I feel very happy today"
评估: 词汇选择准确，但可以更丰富
建议: 可以使用 "delighted", "thrilled", "overjoyed" 等更具体的词汇
```

**词汇搭配检查**
```
常见搭配错误:
- 动词+名词搭配: "do homework" vs "make homework"
- 形容词+名词搭配: "heavy rain" vs "strong rain"  
- 动词+介词搭配: "depend on" vs "depend of"
- 固定短语搭配: "pay attention to" vs "pay attention for"
```

### 3.2 词汇丰富度评估
**词汇多样性计算**
```python
def calculate_vocabulary_diversity(text):
    words = text.lower().split()
    unique_words = set(words)
    
    # Type-Token Ratio (TTR)
    ttr = len(unique_words) / len(words)
    
    # 词汇复杂度 (基于词频统计)
    complexity_score = calculate_word_complexity(words)
    
    # 同义词使用情况
    synonym_usage = check_synonym_variety(text)
    
    diversity_score = (ttr * 40 + complexity_score * 40 + synonym_usage * 20)
    return min(100, diversity_score)
```

**词汇等级分析**
```
词汇分级标准:
- 基础词汇 (1-2000常用词): 权重1.0
- 中级词汇 (2000-5000词): 权重1.5  
- 高级词汇 (5000+词): 权重2.0
- 学术词汇 (AWL学术词汇表): 权重2.5
```

### 3.3 词汇改进建议
**同义词推荐**
```
原词 → 改进建议:
"good" → "excellent", "outstanding", "remarkable"
"big" → "enormous", "substantial", "significant"
"said" → "mentioned", "stated", "explained"

建议逻辑:
1. 考虑语境适当性
2. 考虑用户当前水平
3. 提供使用示例
4. 解释词汇差异
```

**高级表达转换**
```
基础表达 → 高级表达:
"I think" → "In my opinion", "From my perspective"
"very important" → "crucial", "vital", "of paramount importance"
"a lot of" → "numerous", "a substantial amount of"
```

## 4. 表达流畅性评估

### 4.1 连贯性分析
**句子间连接**
```
评估指标:
- 逻辑连接词使用 (however, therefore, moreover)
- 代词指代清晰性
- 主题一致性
- 信息递进合理性

连贯性评分:
- 优秀 (90-100): 逻辑清晰，过渡自然
- 良好 (70-89): 基本连贯，有少量跳跃
- 一般 (50-69): 连接较弱，需要改进
- 较差 (0-49): 逻辑混乱，难以理解
```

**表达自然度**
```
自然度检测:
- 中式英语表达识别
- 生硬翻译痕迹检测
- 母语表达习惯对比
- 地道表达程度评估

示例:
中式表达: "I very like this movie"
自然表达: "I really like this movie" / "I love this movie"
```


### 4.3 流畅性反馈
**改进建议生成**
```
连贯性改进:
"考虑使用连接词如 'however', 'furthermore' 来改善句子间的连接"
"注意代词指代要清晰，避免指代不明"

自然度改进:
"尝试使用更地道的表达：'make a decision' 而不是 'do a decision'"
"避免直译：'eat medicine' 应该是 'take medicine'"

复杂度建议:
"可以尝试使用一些复合句来提高表达的复杂度"
"句子长度变化会让表达更有节奏感"
```

## 5. 任务完成度评估

### 5.1 交流目标评估
**目标达成检查**
```
评估维度:
- 信息完整性: 是否提供了要求的所有信息
- 回应相关性: 是否正确理解并回应了问题
- 交流效果: 是否达到了预期的交流目的
- 角色适应性: 是否符合设定的角色和情境

评分标准:
- 完全达成 (90-100): 全面完成所有要求
- 基本达成 (70-89): 完成主要要求，有小缺失
- 部分达成 (50-69): 完成部分要求，有明显缺失  
- 未达成 (0-49): 未能完成基本要求
```

**内容质量评估**
```
质量指标:
- 信息准确性: 提供的信息是否准确
- 逻辑合理性: 论述是否有逻辑
- 细节丰富度: 是否提供了足够的细节
- 创新性: 是否有独特的见解或表达
```

### 5.2 语境适应性
**正式度匹配**
```
场景分类:
- 正式场景: 学术讨论、商务会议、面试
- 半正式场景: 工作邮件、客户服务
- 非正式场景: 朋友聊天、日常对话

适应性评估:
- 词汇选择是否符合场景正式度
- 语法结构是否适合交流环境
- 语调是否匹配情境需求
```

## 6. 综合评分算法

### 6.1 权重分配
```python
EVALUATION_WEIGHTS = {
    'task_completion': 0.40,    # 任务完成度 40%
    'grammar_accuracy': 0.25,   # 语法准确性 25%
    'vocabulary_usage': 0.20,   # 词汇运用 20%
    'fluency': 0.15            # 表达流畅性 15%
}

def calculate_final_score(scores):
    weighted_score = sum(
        scores[dimension] * EVALUATION_WEIGHTS[dimension]
        for dimension in EVALUATION_WEIGHTS
    )
    return round(weighted_score, 1)
```

### 6.2 星级转换
```python
def score_to_stars(score):
    if score >= 85:
        return 3  # 优秀
    elif score >= 70:
        return 2  # 良好
    elif score >= 55:
        return 1  # 通过
    else:
        return 0  # 需要重新练习
```

## 7. 个性化反馈系统

### 7.1 用户水平适应
**反馈深度调节**
```
初级用户 (雅思5.0-5.5):
- 重点关注基础语法错误
- 提供简单明确的改正建议
- 鼓励性反馈为主

中级用户 (雅思5.5-6.0):
- 语法和词汇并重
- 提供详细的解释和例句
- 挑战性建议适中

高级用户 (雅思6.0+):
- 重点关注表达自然度和复杂度
- 提供高级表达建议
- 更多挑战性改进建议
```

### 7.2 学习偏好适应
**反馈风格调节**
```
数据导向型用户:
- 提供详细的分数和统计数据
- 强调量化的改进指标
- 对比历史表现

感受导向型用户:
- 提供鼓励性的描述性反馈
- 强调进步和成长
- 减少数字评分的强调

实用导向型用户:
- 重点提供实用的改进建议
- 提供具体的替换表达
- 推荐相关练习资源
```

## 9. 数据模型设计

### 9.1 评估记录表
```sql
CREATE TABLE evaluation_records (
    evaluation_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    practice_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    level_id BIGINT NOT NULL,
    
    -- 综合评分
    overall_score DECIMAL(5,2),
    star_rating INT,
    
    -- 各维度评分
    task_completion_score DECIMAL(5,2),
    grammar_accuracy_score DECIMAL(5,2),
    vocabulary_usage_score DECIMAL(5,2),
    fluency_score DECIMAL(5,2),
    
    -- 详细分析数据
    analysis_data JSON,
    feedback_data JSON,
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (practice_id) REFERENCES practice_records(practice_id),
    FOREIGN KEY (user_id) REFERENCES users(user_id),
    FOREIGN KEY (level_id) REFERENCES levels(level_id)
);
```

### 9.2 错误记录表
```sql
CREATE TABLE error_records (
    error_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    evaluation_id BIGINT NOT NULL,
    error_type VARCHAR(50), -- grammar, vocabulary, fluency
    error_subtype VARCHAR(50), -- tense, word_choice, coherence
    error_position INT, -- 错误在文本中的位置
    original_text TEXT,
    suggested_correction TEXT,
    explanation TEXT,
    severity ENUM('minor', 'major', 'critical'),
    
    FOREIGN KEY (evaluation_id) REFERENCES evaluation_records(evaluation_id)
);
```

### 9.3 反馈模板表
```sql
CREATE TABLE feedback_templates (
    template_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_type VARCHAR(50), -- grammar_error, vocabulary_suggestion
    error_pattern VARCHAR(100),
    feedback_template TEXT,
    explanation_template TEXT,
    example_sentences JSON,
    target_user_level ENUM('beginner', 'intermediate', 'advanced'),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
