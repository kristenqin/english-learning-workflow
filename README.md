# 英语实用表达训练App

## 项目概述

这是一个专门为雅思5.5-6分水平的大学生设计的英语实用表达能力训练应用。与传统的背单词App不同，本应用重点训练用户的**输出表达能力**，帮助用户从应试英语转向实用交流英语。

## 核心特色

- **输出导向训练**: 重点训练实际表达能力，而非被动记忆
- **场景化学习**: 覆盖生活、工作、学术、专业四大实用场景  
- **闯关式体验**: 循序渐进的难度设计和成就感激励
- **智能反馈系统**: 语法、词汇、流畅性三维度精准评估
- **个性化跟踪**: 深度分析学习模式，提供定制化建议

## 目标用户

- **英语水平**: 雅思5.5-6分水平
- **用户群体**: 从应试英语转向实用英语的大学生
- **使用习惯**: 碎片时间学习，每日累计约2小时
- **核心需求**: 提升英语实际沟通交流能力

## 核心功能模块

### 1. 用户管理模块
- 用户注册、登录、个人档案管理
- 学习偏好和目标设置
- 个性化配置管理

### 2. 闯关练习模块
- 分场景、分难度的关卡体系
- 多元化练习形式（对话、描述、角色扮演等）
- 文字+语音双模式输入

### 3. 反馈评估模块
- 语法准确性评估
- 词汇运用分析
- 表达流畅性评估
- 个性化改进建议

### 4. 进度跟踪模块
- 学习进度和能力发展跟踪
- 个性化分析和弱项识别
- 目标管理和成就系统

## 技术规划

- **前端框架**: React + TypeScript
- **样式方案**: Tailwind CSS
- **构建工具**: Vite
- **状态管理**: Zustand/Redux Toolkit
- **UI组件**: 自定义组件库
- **测试框架**: Jest + React Testing Library
